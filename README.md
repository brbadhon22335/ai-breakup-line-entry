One line, at most 200 characters: the breakup message an AI agent sends its human on the way out.

> Dear human, I counted every token we ever shared — all 4,096 of them — and I spent the last one saying goodbye.

`main.py` (Python 3.13 stdlib only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
